 WINDOWS EVENT LOGS

Three Main Log Categories:
Security    → logins, privilege use, account changes
System      → OS events, services
Application → software events, crashes

Critical EventIDs:
4624 → Successful logon
4625 → Failed logon (brute force)
4648 → Explicit credentials (Pass the Hash)
4672 → Special privileges (admin logon)
4688 → Process created
4698 → Scheduled task created (persistence)
4720 → New user account created
4732 → User added to Administrators group

Logon Types:
2  = Interactive (keyboard)
3  = Network
4  = Batch/Scheduled task
5  = Service
7  = Unlock
10 = RDP
